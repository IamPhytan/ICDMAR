# Interface de Cinématique Directe pour les MAnipulateurs Redondants

Interface de calcul de cinématique pour les manipulateurs redondants

## Utilisation

Ajouter les membres du bras à tracer, avec la syntaxe suivante :

```
<longueur> <largeur> <angle>
```

Par exemple, pour un membre long de 5 unités, large de 2 unités, avec un angle de 60 degrés par rapport au membre précédent :

```
5 2 60
```
